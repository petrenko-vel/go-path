# Go Path

Платформа для изучения Go. Сборка не нужна: открой `index.html` двойным кликом.

- `css/style.css` — стили
- `js/roadmap.js` — карта обучения, ссылки, расписание данных
- `js/topics.js` — конспекты тем
- `js/app.js` — логика приложения

Прогресс хранится в localStorage браузера (раздел «Данные» — экспорт/импорт).

## GitHub Pages
1. Создай репозиторий и залей туда содержимое папки.
2. Settings → Pages → Branch: `main`, папка `/ (root)` → Save.
3. Сайт появится на `https://<логин>.github.io/<репозиторий>/`.
